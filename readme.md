# 🌐 Personal Portfolio Website

A sleek, modern, and fully responsive **Personal Portfolio Website** built from scratch to showcase my frontend development journey, core skills, earned certificates, and technical projects. 

🚀 **[View Live Demo](YOUR_LIVE_DEMO_URL_HERE)**

---

## 🎨 Features

- **📱 Fully Responsive Design:** Optimised for desktop, tablet, and mobile device viewports.
- **🚀 Dynamic Project Gallery:** Cards featuring hover animations, technical tags, and live links.
- **📜 Verified Credentials:** Dedication section highlighting professional courses and certifications.
- **✉️ Interactive Contact Form:** Clean user form for direct inquiries and networking.
- **✨ Smooth Scrolling:** Intuitive UI/UX navigation with fluid transition effects across pages.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture for structured web formatting.
- **CSS3:** Custom layouts using modern Flexbox, CSS Grid, and custom animations.
- **JavaScript (ES6+):** Interactive behaviors, project filtering, and structural page transitions.

## 🚀 Getting Started

Follow these simple steps to replicate or explore this application locally:

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
```bash
cd YOUR_REPO_NAME
```

### 3. Launch Locally
Simply double-click `index.html` to open it in your preferred browser, or host it locally using the **Live Server** extension on Visual Studio Code.

## 📝 Customisation Checklist

To personalize this project file for your own profile:
1. Update text copy across the profile overview, timeline, and footer sections in `index.html`.
2. Swap placeholder profile photos and asset images inside the `assets/images/` directory.
3. Modify the CSS root variables in `style.css` to align with your personal color palette choice.
4. Update the interactive contact form target destination to your preferred backend handling endpoint (e.g., Formspree, Web3Forms, or EmailJS).
